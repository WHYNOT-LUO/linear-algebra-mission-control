Optional feature — bring your own key

Everything else on this site works with no setup: the 30-day plan, progress tracking, flashcards, quizzes and the visualizations. The tutor is the one part that needs an API key.

This site is hosted on GitHub Pages, which serves static files only — there is no server to keep a secret on. Shipping my own key would mean publishing it in the page source for anyone to copy and spend. So the tutor asks each visitor for their own key instead, and keeps it in that visitor's browser.

🌀 Visualizations
Interactive geometry — see linear algebra come alive.
Matrix Transformation
Week 1
a 1.0 b 0.5
c 0.0 d 1.0
Drag sliders to change matrix [[a,b],[c,d]]. Watch the unit square and basis vectors transform. The determinant = signed area of the transformed square.
Eigenvectors Live
Week 3–4
λ₁ 2.0 λ₂ 0.5
Angle θ 45°
Eigenvectors (coloured arrows) stay on the same line — only scaled by eigenvalue λ. All other vectors rotate. Drag λ₁, λ₂ negative to see reflection.
Projection onto a Line
Week 3
Line angle 35° bₓ 1.5
Vector b projects onto line a. The projection p = (aᵀb/aᵀa)a. Error e = b−p is always perpendicular to a.
SVD: Circle → Ellipse
Week 4
σ₁ 2.0 σ₂ 0.7
Rotation 30°
Every matrix maps the unit circle to an ellipse. σ₁, σ₂ are the singular values — semi-axis lengths. The singular vectors U (output) and V (input) are the ellipse axes.
